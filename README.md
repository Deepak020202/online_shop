# Dockerized Web App Deployment with Multi-Stage Builds  


##  Aim  
Optimize image size, improve security, and enhance deployment performance. By leveraging Linux, Git, and Docker, this project ensures a streamlined, scalable, and production-ready application.  

## 🛠 Technology Stack  
- **Cloud Provider**: AWS EC2  
- **Version Control**: Git & GitHub  
- **Operating System**: Linux (Ubuntu)  
- **Containerization**: Docker (with Multi-Stage Builds)  
- **Other Tools**: DockerHub  

## 🔄 Project Workflow & Steps  

1️⃣ **Create and Set Up an EC2 Instance via SSH**  
2️⃣ **Initialize Git and Set Up a Branch**  
3️⃣ **Install and Set Up Docker on EC2**  
4️⃣ **Create a Dockerfile and Apply Multi-Stage Builds**  
5️⃣ **Push Your Image to DockerHub**
